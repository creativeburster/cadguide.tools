# CAD Exchanger Getting Started Guide: Setup, Key Features, and Workflow Overview

Mobile 3D CAD viewer and converter for multiple file formats.

## Overview

CAD Exchanger is a 3d modeling tool developed in USA. It is available on Android, iOS with a Freemium pricing model starting at Free. The current version is 3.25.

## Key Capabilities

- **Category**: 3D Modeling
- **Geometry Engine**: CAD Exchanger SDK
- **Supported Standards**: STEP, IGES, STL, JT, Parasolid
- **Platforms**: Android, iOS
- **Pricing**: Freemium (from Free)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Android, iOS and meets the minimum hardware specifications for 3d modeling workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch CAD Exchanger and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (STEP, IGES, STL, JT, Parasolid) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage CAD Exchanger's core 3d modeling capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

CAD Exchanger uses a Freemium pricing model with a starting price of Free. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

CAD Exchanger supports the following industry-standard formats: STEP, IGES, STL, JT, Parasolid. This ensures interoperability with other tools in the 3D Modeling ecosystem.

## Summary

CAD Exchanger provides 3d modeling capabilities with CAD Exchanger SDK under the hood, running on Android, iOS. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
