# Synopsys Fusion Compiler Getting Started Guide: Setup, Key Features, and Workflow Overview

Next-generation RTL-to-GDSII EDA compiler from Synopsys.

## Overview

Synopsys Fusion Compiler is a eda tool developed in USA. It is available on Linux with a Subscription pricing model starting at $50000. The current version is 2024.

## Key Capabilities

- **Category**: EDA
- **Geometry Engine**: Synopsys Fusion Engine
- **Supported Standards**: GDSII, LEF/DEF, Liberty, Verilog
- **Platforms**: Linux
- **Pricing**: Subscription (from $50000)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Linux and meets the minimum hardware specifications for eda workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Synopsys Fusion Compiler and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (GDSII, LEF/DEF, Liberty, Verilog) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Synopsys Fusion Compiler's core eda capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## File Format Support

Synopsys Fusion Compiler supports the following industry-standard formats: GDSII, LEF/DEF, Liberty, Verilog. This ensures interoperability with other tools in the EDA ecosystem.

Synopsys Fusion Compiler provides eda capabilities with Synopsys Fusion Engine under the hood, running on Linux. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
