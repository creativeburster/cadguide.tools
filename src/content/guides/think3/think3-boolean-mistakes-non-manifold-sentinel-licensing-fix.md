# ThinkDesign (think3) Boolean Mistakes, Non-Manifold Solids, and Sentinel Licensing Setup

ThinkDesign (formerly think3) is a hybrid modeling CAD system with unique support for non-manifold solids. Three issue categories dominate user problems: excessive Boolean operations that bloat the model tree, non-manifold geometry from incorrect modeling steps, and Sentinel licensing failures after upgrades. Each has documented fixes from DPT's official help system.

## Issue 1: Excessive Boolean Operations Corrupting the Model Tree

**Symptom**: The Model Structure becomes extremely complex after multiple Boolean operations, making it difficult to reorder features, modify parameters, or remove specific operations.

**Root Cause**: Using Boolean operations (Union, Subtract, Intersect) where features (Slot, Pocket, Protrusion) would be more appropriate. Each Boolean operation between n solids creates n branches in the Model Structure.

### Disadvantages of Excessive Booleans

Per the official DPT documentation:

1. **Reordering is blocked**: Moving features inside the Model Structure becomes complex because Boolean operations create concatenated event chains
2. **No pattern operations**: You cannot perform pattern operations on parts of a solid generated by Boolean operations. If a pocket was created by subtracting a solid, it cannot be patterned. Create the pocket with the Slot feature instead.
3. **No mirror operations**: Same restriction as patterns — mirror operations fail on Boolean-generated geometry
4. **No variable assignment**: You cannot assign a variable to a Boolean event, while features accept variable control for parametric design
5. **Removal is difficult**: Boolean operations cannot be immediately removed. You must first isolate and dismantle them. If the Boolean event is a combination of multiple events, dismantling is time-consuming

### Fix: Replace Booleans with Features

| Instead of... | Use... |
|---------------|--------|
| Boolean Subtract to make a pocket | **Slot** feature (supports patterns and variables) |
| Boolean Union to join solids | **Linear Protrusion** (maintains clean history) |
| Boolean Subtract for holes | **Hole** feature (supports pattern and mirror) |

If you must use Booleans, execute pattern operations **before** the Boolean, not after.

## Issue 2: Non-Manifold Solids

**Symptom**: The model contains solids that are not "real" workpieces — they have internal walls, shared edges between more than two faces, or disconnected shells within a single solid.

**Root Cause**: Non-manifold solids can result from incorrect modeling steps or unexpected results when converting legacy surfaces into solids. However, ThinkDesign treats non-manifold solids as a **feature, not a bug** — they add power and flexibility in solid modeling.

### Working with Non-Manifold Solids

ThinkDesign allows you to:

1. **Perform Booleans with open solids**: Operations that would fail in strict manifold-only CAD systems work in ThinkDesign
2. **Apply features to non-manifold objects**: Features like fillets, chamfers, and shells can be applied to non-manifold geometry
3. **Create 2D drawings from non-manifold objects**: Drawing generation works with non-manifold solids

### When to Fix Non-Manifold Geometry

In many cases, you can **ignore** the non-manifold condition and continue working. However, if you need to export to a strict manifold format (STL for 3D printing, STEP for downstream CAM), you should:

1. Use **Locating Open (Disconnected) Edges** to identify where the solid is open
2. Repair the edges by stitching or filling gaps
3. Verify the result with ThinkDesign's solid validation tools

### Open vs. Non-Manifold Solids

- **Open solids**: Have disconnected edges — the solid is not fully sealed
- **Non-manifold solids**: Have valid topology but with non-physical configurations (e.g., two solids sharing a single face)
- ThinkDesign handles both, but they behave differently during Boolean operations and feature application

## Issue 3: Sentinel Licensing Failures

**Symptom**: After installing or upgrading ThinkDesign 2015.2 or later, the program closes immediately after the splash screen with an error dialog. No demo mode is available.

**Root Cause**: ThinkDesign 2015.2+ uses **Sentinel** licensing by Thales (formerly SafeNet). The old think3 License Administrator (`cladmin.exe`) and FlexNet licenses are no longer used. USB dongles from the old system are not recognized.

### Fix: Sentinel License Setup

#### Node-Locked License (Single PC)

1. Install ThinkDesign and insert the Sentinel dongle into a USB port — the dongle should light up
2. Open the **Admin Control Center (ACC)** by typing `http://localhost:1947` in a web browser
3. Select **Sentinel Keys** in the left menu
4. Find the row with **Driverless Configuration** and click the **C2V** button
5. The `.c2v` (Customer-to-Vendor) file saves to your Downloads folder
6. Email the `.c2v` file to `pwdrelease@dptcorporate.com`
7. DPT returns a `.v2c` (Vendor-to-Customer) file
8. In the ACC, use **Update/Attach** to upload the `.v2c` file and activate the license

#### Floating License (Network)

1. Install the Floating Licensing package on the license server
2. Upload the `.v2cp` file via the ACC on the server
3. On client PCs, set the environment variable:
   - **Variable name**: `DPT_LIC_HOSTNAME`
   - **Variable value**: `LOCALHOST` (local only), `Server_Name` (floating only), or leave unset for both
4. For VPN connections: In ACC → **Configuration → Access to Remote License Managers** → enter server name in **Remote License Search Parameters**
5. For local network: Simply set `DPT_LIC_HOSTNAME = server_name`

To set the environment variable: **Control Panel → System → Advanced System Settings → Advanced tab → Environment Variables → System variables → New**

## Issue 4: STEP File Import Errors

**Symptom**: "Internal error when loading a STEP file" or ThinkDesign closes when opening a STEP file.

**Fix**: These issues were fixed in ThinkDesign 2024.1 SP2:

- Fixed "Internal error when loading a STEP file"
- Fixed "TD closes when opening a STEP file"
- Fixed "Solid Shells with Inverted Normals"
- Fixed "Missing spheres in loading an IGES model"

Update to ThinkDesign 2024.1 SP2 or later. If the issue persists, check the **STEP conversion log file**, which has four sections:

1. **INFORMATION**: STEP format (AP203/AP214) and source system
2. **Report STEP**: Entity types, counts, warnings, errors
3. **Report GDX**: Internal intermediate format conversion results
4. **Report EKGK**: Final think3 format conversion results

The warnings and errors sub-sections in each report identify specific conversion failures.
