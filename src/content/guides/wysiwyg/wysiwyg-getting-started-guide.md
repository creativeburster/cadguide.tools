# WYSIWYG Getting Started Guide: Setup, Key Features, and Workflow Overview

The standard for lighting design and pre-visualization.

## Overview

WYSIWYG is a specialized tool developed in USA. It is available on Windows with a Subscription pricing model starting at $1200. The current version is 2024.

## Key Capabilities

- **Category**: Specialized
- **Geometry Engine**: Cast Core
- **Supported Standards**: DWG, OBJ, SKP
- **Platforms**: Windows
- **Pricing**: Subscription (from $1200)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for specialized workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch WYSIWYG and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (DWG, OBJ, SKP) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage WYSIWYG's core specialized capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

WYSIWYG uses a Subscription pricing model with a starting price of $1200. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

WYSIWYG supports the following industry-standard formats: DWG, OBJ, SKP. This ensures interoperability with other tools in the Specialized ecosystem.

## Summary

WYSIWYG provides specialized capabilities with Cast Core under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
