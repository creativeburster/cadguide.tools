# ArcSite Getting Started Guide: Setup, Key Features, and Workflow Overview

Mobile CAD and floor plan creation tool for field work.

## Overview

ArcSite is a 2d cad tool developed in USA. It is available on Android, iOS with a Subscription pricing model starting at $19. The current version is 2025.

## Key Capabilities

- **Category**: 2D CAD
- **Geometry Engine**: Custom Mobile Engine
- **Supported Standards**: PDF
- **Platforms**: Android, iOS
- **Pricing**: Subscription (from $19)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Android, iOS and meets the minimum hardware specifications for 2d cad workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch ArcSite and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (PDF) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage ArcSite's core 2d cad capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

ArcSite uses a Subscription pricing model with a starting price of $19. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

ArcSite provides 2d cad capabilities with Custom Mobile Engine under the hood, running on Android, iOS. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
