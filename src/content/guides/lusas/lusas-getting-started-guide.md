# LUSAS Getting Started Guide: Setup, Key Features, and Workflow Overview

UK-based finite element analysis software for bridge, civil, structural, composites, and general engineering applications with specialized modules.

## Overview

LUSAS is a cae/cam tool developed in UK. It is available on Windows with a Perpetual pricing model starting at Free. The current version is 21.0.

## Key Capabilities

- **Category**: CAE/CAM
- **Geometry Engine**: LUSAS FEA Engine
- **Supported Standards**: Eurocode, AASHTO, British Standards
- **Platforms**: Windows
- **Pricing**: Perpetual (from Free)
- **Country of Origin**: UK

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for cae/cam workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch LUSAS and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (Eurocode, AASHTO, British Standards) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage LUSAS's core cae/cam capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

LUSAS uses a Perpetual pricing model with a starting price of Free. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

LUSAS supports the following industry-standard formats: Eurocode, AASHTO, British Standards. This ensures interoperability with other tools in the CAE/CAM ecosystem.

## Summary

LUSAS provides cae/cam capabilities with LUSAS FEA Engine under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
