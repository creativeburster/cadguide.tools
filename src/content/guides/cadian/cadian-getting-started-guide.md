# CADian Getting Started Guide: Setup, Key Features, and Workflow Overview

Korean 2D CAD software with 30+ years of development history, offering reliable CAD drafting and design capabilities.

## Overview

CADian is a 2d cad tool developed in South Korea. It is available on Windows with a Perpetual pricing model starting at $300. The current version is CADian.

## Key Capabilities

- **Category**: 2D CAD
- **Geometry Engine**: CADian Engine
- **Supported Standards**: KS, ISO
- **Platforms**: Windows
- **Pricing**: Perpetual (from $300)
- **Country of Origin**: South Korea

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for 2d cad workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch CADian and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (KS, ISO) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage CADian's core 2d cad capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

CADian uses a Perpetual pricing model with a starting price of $300. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

CADian supports the following industry-standard formats: KS, ISO. This ensures interoperability with other tools in the 2D CAD ecosystem.

## Summary

CADian provides 2d cad capabilities with CADian Engine under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
