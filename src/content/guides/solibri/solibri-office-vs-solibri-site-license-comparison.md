# Solibri Office vs Solibri Site: Choosing the Right Solibri License for Your Team

Solibri's licensing model confuses most people I talk to. There's Solibri Office, Solibri Site, and Solibri Cloud — and the differences aren't obvious from the product pages. I've helped several companies choose the right license, and the wrong choice can waste thousands of dollars per year. Here's what each license includes and when to choose each.

## Solibri Product Lineup

Solibri offers three main products:

- **Solibri Office**: Desktop application for BIM coordinators and model checkers. Full ruleset management, clash detection, reporting, and issue management.
- **Solibri Site**: Desktop application for field teams and reviewers. View models, review issues, and create BCF reports — but limited checking capabilities.
- **Solibri Cloud**: Cloud-based model checking and issue sharing platform. Extends Office with cloud processing and team collaboration.

## Feature Comparison

### Model Import and Viewing

**Solibri Office**: Full IFC import, model federation, 3D navigation, sectioning, and measurement. Supports large federated models.

**Solibri Site**: Same IFC import and viewing capabilities as Office. Can open and view any model that Office creates.

**Winner**: Tie. Both can import and view IFC models.

### Ruleset Management

**Solibri Office**: Full Ruleset Manager. Create, edit, and customize rulesets. Access to all rule templates and libraries. Can export and share rulesets.

**Solibri Site**: Can load and run existing rulesets, but cannot create or edit them. Limited to running checks that someone else has configured.

**Winner**: Office for ruleset creation. Site for running pre-configured checks.

### Clash Detection

**Solibri Office**: Full clash detection including General Intersection, Clash Detection Matrix, Clearance checks, and custom rules. Can configure tolerances, filters, and exclusions.

**Solibri Site**: Can run clash detection using pre-configured rulesets, but cannot adjust settings. Results are viewable but not configurable.

**Winner**: Office for configuration. Site for execution.

### Issue Management

**Solibri Office**: Full issue management — create, edit, assign, prioritize, and close issues. BCF import and export. Issue batching and bulk operations.

**Solibri Site**: Can view, comment on, and close issues. Can create BCF reports. Cannot create new issues from clash results (depends on ruleset configuration).

**Winner**: Office for issue management. Site for issue review.

### Reporting

**Solibri Office**: Full report generator. Create custom report templates, export to PDF/HTML/PowerPoint, include viewpoints and statistics.

**Solibri Site**: Can generate basic reports from existing templates. Cannot create custom report templates.

**Winner**: Office for reporting. Site for basic report generation.

### Model Comparison

**Solibri Office**: Compare two model versions to identify added, removed, and modified elements. Visual diff with color coding.

**Solibri Site**: Can view model comparison results created in Office, but cannot run new comparisons.

**Winner**: Office for model comparison.

### Information Takeoff

**Solibri Office**: Full information takeoff — count components, calculate areas/volumes, export to Excel. Create custom takeoff formulas.

**Solibri Site**: View takeoff results created in Office. Cannot create new takeoff definitions.

**Winner**: Office for takeoff.

### Cloud Features

**Solibri Office with Solibri Cloud**: Upload models to Solibri Cloud for cloud-based processing. Share issues with team members in real-time. Cloud-based model viewing without desktop application.

**Solibri Site with Solibri Cloud**: Access cloud-shared models and issues. Review and comment on issues in the cloud. Limited cloud processing capabilities.

**Winner**: Office + Cloud for full cloud workflow. Site + Cloud for cloud-based review.

## When to Choose Solibri Office

Solibri Office is for the **BIM Coordinator** or **BIM Manager** — the person responsible for running coordination checks, managing rulesets, and producing reports.

Choose Office when:
- You're the designated BIM coordinator on the project
- You need to create and maintain custom rulesets
- You produce coordination reports for the team
- You manage the issue workflow (creating, assigning, closing issues)
- You need model comparison between versions
- You need information takeoff for quantity verification

Typical users: BIM Managers, BIM Coordinators, Design Lead, Quality Managers.

## When to Choose Solibri Site

Solibri Site is for **team members who need to review issues** but don't need to create or configure checks.

Choose Site when:
- You're a discipline lead who needs to review issues assigned to your team
- You're a field supervisor who needs to view models and issues on site
- You're a client representative who needs to review coordination progress
- You need to create BCF reports from existing issues
- You don't need to create or edit rulesets

Typical users: Discipline Leads, Architects, Engineers, Field Supervisors, Client Representatives.

## Pricing Considerations

**Solibri Office**: Approximately $3,000-$4,000/year per user.

**Solibri Site**: Approximately $1,000-$1,500/year per user (significantly cheaper than Office).

**Solibri Cloud**: Additional subscription on top of Office or Site. Pricing varies by project size and number of models.

### Cost-Effective Team Setup

For a typical project with 10 team members:

- **1-2 Solibri Office licenses** for the BIM Coordinator(s): $3,000-$8,000/year
- **3-5 Solibri Site licenses** for discipline leads and reviewers: $3,000-$7,500/year
- **Total**: $6,000-$15,500/year

Compare this to giving everyone Office licenses: $30,000-$40,000/year. The savings from using Site for reviewers are significant.

## Solibri Cloud: Is It Worth It?

Solibri Cloud adds cloud-based processing and collaboration. Key benefits:

- **Cloud processing**: Run checks on large models without tying up your desktop
- **Real-time issue sharing**: Team members see issues immediately without BCF file exchange
- **Cloud model viewing**: Review models in a web browser without the desktop application
- **Automated checking**: Schedule checks to run automatically when new models are uploaded

### When Cloud Is Worth It

- Large projects with frequent model updates (daily or weekly)
- Distributed teams who can't meet in person for coordination
- Projects requiring automated checking without manual intervention
- Teams using BIMcollab or other cloud-based BCF platforms

### When Cloud Is Not Worth It

- Small projects with infrequent model updates
- Co-located teams who meet weekly for coordination
- Projects with simple coordination requirements
- Budget-constrained projects where desktop checking is sufficient

## My Recommendation

For most projects:

1. **Buy 1-2 Office licenses** for the BIM Coordinator(s)
2. **Buy 3-5 Site licenses** for discipline leads and reviewers
3. **Add Solibri Cloud** only for large projects with distributed teams

Don't buy Office for everyone — it's a waste of money. Most team members only need to review issues, not create rulesets. Site gives them the functionality they need at a fraction of the cost.

If you're a small firm with only 1-2 people doing BIM coordination, a single Office license is sufficient. You can share BCF files via email or ACC Docs instead of using Solibri Cloud.
