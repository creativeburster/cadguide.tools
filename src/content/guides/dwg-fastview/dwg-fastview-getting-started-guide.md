# DWG FastView Getting Started Guide: Setup, Key Features, and Workflow Overview

Lightweight cross-platform CAD viewer & editor.

## Overview

DWG FastView is a viewer tool developed in China. It is available on Windows, Web, Android, iOS with a Freemium pricing model starting at Free. The current version is 10.1.0.

## Key Capabilities

- **Category**: Viewer
- **Geometry Engine**: GstarCAD Core
- **Supported Standards**: DWG, DXF
- **Platforms**: Windows, Web, Android, iOS
- **Pricing**: Freemium (from Free)
- **Country of Origin**: China

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows, Web, Android, iOS and meets the minimum hardware specifications for viewer workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch DWG FastView and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (DWG, DXF) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage DWG FastView's core viewer capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

DWG FastView uses a Freemium pricing model with a starting price of Free. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

DWG FastView supports the following industry-standard formats: DWG, DXF. This ensures interoperability with other tools in the Viewer ecosystem.

## Summary

DWG FastView provides viewer capabilities with GstarCAD Core under the hood, running on Windows, Web, Android, iOS. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
