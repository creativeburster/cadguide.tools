# DWG FastView Mobile CAD Viewer Errors: PC v9.5.0 Crash on Launch from Version Bug Requiring Uninstall and v9.4.0 Reinstall, Drawings Not Opening from Insufficient Running Memory or File Errors Requiring Memory Check, WhatsApp Shared Drawings Not Opening from Bug Requiring Latest Version Update, iCloud and Cloud Storage Access Limitations Requiring Local File Import, and Free Features Moved Behind Subscription Paywall Requiring Premium Upgrade or Alternative Apps

DWG FastView's PC version stability, file opening, third-party sharing, cloud access, and subscription model produce errors from version bugs, memory constraints, format handling, and feature gating. This guide covers the 5 most common DWG FastView problems with diagnostic steps and community-verified fixes from DWG FastView Blog and user reviews.

## 1. PC v9.5.0 Crash on Launch from Version Bug

### Symptom

DWG FastView PC version 9.5.0 crashes unexpectedly during startup or when opening DWG/DXF files. The application is unstable and disrupts workflow. Frequent crashes make the software unusable.

### Root Cause

"We have identified a critical bug in the PC version 9.5.0 of DWG FastView that may cause the application to crash unexpectedly during startup or when opening DWG/DXF files." This is a version-specific bug in the v9.5.0 build. A simple reinstall of the same version doesn't fix it because the problem lies within the specific build.

### Fix

1. **Uninstall v9.5.0 completely**:
   - "Please completely uninstall v9.5.0 from your system"
   - "A simple reinstall may not fix the issue, as the problem lies within the specific version 9.5.0 build"
   - Go to Settings > Apps > Apps & features
   - Find "DWG FastView" and select Uninstall
   - Ensure complete removal

2. **Install stable v9.4.0**:
   - "Download the v9.4.0 installer for your system language"
   - Download from the official DWG FastView website
   - Select the correct language version
   - Run the installer and follow on-screen instructions

3. **Restart computer after installation**:
   - "Restart your computer after the installation is complete to ensure a clean start"
   - This ensures all components are properly registered
   - Launch DWG FastView v9.4.0
   - Verify it opens without crashing

4. **Wait for patched update**:
   - "Our development team is working diligently to identify the root cause"
   - "We will release a patched update (v9.5.1 or later) as soon as the issue is fully resolved"
   - Monitor the DWG FastView blog for update announcements
   - Upgrade when the patched version is released

5. **Contact support if issues persist**:
   - "If you continue to experience issues after reinstalling v9.4.0"
   - "Please do not hesitate to contact our support team"
   - "Providing details such as your operating system version and any specific error messages can help"
   - Email: support.mc@gstarcad.net

### Community Report

> "We have identified a critical bug in the PC version 9.5.0 of DWG FastView that may cause the application to crash unexpectedly during startup or when opening DWG/DXF files. Please completely uninstall v9.5.0 and install the stable v9.4.0 version. A simple reinstall may not fix the issue, as the problem lies within the specific version 9.5.0 build."

## 2. Drawings Not Opening from Insufficient Running Memory

### Symptom

Cannot open a DWG drawing in DWG FastView on mobile. The file appears valid but doesn't open. No error message is shown. Some large drawings open fine, others don't.

### Root Cause

"DWG FastView doesn't limit the size of drawing. As long as the running memory of your mobile phone is enough, DWG FastView can open any-sized drawings. Sometimes users can't open, because the running memory of your mobile is not enough for opening the drawings or the drawings themselves have errors." Mobile devices have limited RAM. Large DWG files require significant memory to parse and render. When the device's available RAM is insufficient, the app can't open the file.

### Fix

1. **Check available memory**:
   - "The running memory of your mobile is not enough for opening the drawings"
   - Close all other apps before opening the drawing
   - Check available RAM in device settings
   - Free up memory by clearing app caches

2. **Restart the device**:
   - Restarting clears the RAM
   - Kills background processes
   - Frees memory for DWG FastView
   - Try opening the drawing immediately after restart

3. **Check for file errors**:
   - "The drawings themselves have errors"
   - Try opening the file on a PC with AutoCAD or GstarCAD
   - If the file is corrupted, run RECOVER or AUDIT
   - Save a cleaned version and transfer to mobile

4. **Simplify the drawing**:
   - On a PC, reduce the drawing complexity
   - Remove unnecessary layers, blocks, and xrefs
   - Purge unused elements
   - Save as a simpler DWG and transfer to mobile

5. **Use DWG FastView on PC for large files**:
   - If the file is too large for mobile
   - Use DWG FastView PC version
   - PC has more RAM and processing power
   - Sync the file to mobile cloud after viewing

6. **Check filename for special characters**:
   - "Does the filename contain punctuations or spaces? If so, rename it"
   - Rename the file to use only alphanumeric characters
   - Remove spaces and special characters
   - Try opening after renaming

### Community Report

> "DWG FastView doesn't limit the size of drawing. As long as the running memory of your mobile phone is enough, DWG FastView can open any-sized drawings. Sometimes users can't open, because the running memory of your mobile is not enough or the drawings themselves have errors. Does the filename contain punctuations or spaces? If so, rename it."

## 3. WhatsApp Shared Drawings Not Opening from Bug

### Symptom

Receiving a DWG file via WhatsApp. Trying to open it in DWG FastView. The file doesn't open or the app doesn't recognize it. This worked before but stopped working.

### Root Cause

"This is a bug fixed recently." A bug in DWG FastView prevented opening drawings shared through third-party programs like WhatsApp. The file association or intent handling was broken. The bug was fixed in a recent update.

### Fix

1. **Update DWG FastView to latest version**:
   - "Please update DWG FastView to latest version"
   - "This is a bug fixed recently"
   - Go to Google Play Store or Apple App Store
   - Update to the latest version

2. **Save the file locally first**:
   - Instead of opening directly from WhatsApp
   - Save the file to the device's local storage
   - Open DWG FastView
   - Use File > Open to browse to the saved file

3. **Check file association**:
   - After updating, ensure DWG FastView is the default app for .dwg files
   - On Android: Settings > Apps > Default Apps > DWG files
   - On iOS: Open In > DWG FastView
   - This ensures WhatsApp opens DWG files in DWG FastView

4. **Contact support if still not working**:
   - "If you still can't open, contact us here"
   - "Remember to provide your device info such as android 9, brand"
   - "And your DWG FastView account email"
   - Email: support.mc@gstarcad.net

5. **Use alternative sharing method**:
   - If WhatsApp sharing doesn't work
   - Share via email, Google Drive, or Dropbox
   - Open from the cloud storage app
   - Or save locally and open from DWG FastView

### Community Report

> "Why can't I open the drawing sent or received in 3rd party programs such as WhatsApp? Please update DWG FastView to latest version. This is a bug fixed recently. If you still can't open, contact us and remember to provide your device info such as android 9, brand and your DWG FastView account email."

## 4. iCloud and Cloud Storage Access Limitations

### Symptom

Using DWG FastView on iPad or tablet. Drawings synced from PC to iCloud. DWG FastView can't access iCloud files. The local file option only works with files from DWG FastView's own cloud. Website upload requires Flash (which is obsolete).

### Root Cause

DWG FastView's cloud integration is limited to its own cloud service, Google Drive, Dropbox, OneDrive, Box, and WebDAV. Direct iCloud access is not supported on iOS. The web upload previously required Adobe Flash, which is no longer supported by modern browsers.

### Fix

1. **Use supported cloud services**:
   - "Open files directly from Google Drive, Dropbox, OneDrive, Box & WebDAV"
   - Instead of iCloud, use one of the supported cloud services
   - Upload DWG files to Google Drive or Dropbox from PC
   - Access from DWG FastView on mobile

2. **Import files locally**:
   - Save the DWG file to the device's local storage
   - Use Files app on iOS to move the file
   - Open DWG FastView and use File > Open
   - Browse to the local file location

3. **Use DWG FastView cloud sync**:
   - "Sync across phone, tablet & PC in one tap"
   - Upload from PC using DWG FastView's cloud
   - Sync to mobile device
   - This is the intended cross-platform workflow

4. **Use WebDAV for network access**:
   - If files are on a network drive
   - Configure WebDAV access
   - Add the WebDAV server in DWG FastView
   - Access files directly from the server

5. **Transfer via email**:
   - Email the DWG file to yourself
   - Open the email on the mobile device
   - Tap the attachment and select "Open in DWG FastView"
   - This bypasses cloud storage limitations

6. **Rename files for iOS compatibility**:
   - "Does the filename contain punctuations or spaces? If so, rename it"
   - iOS is stricter about filenames
   - Remove spaces and special characters
   - Use only alphanumeric characters and underscores

### Community Report

> "DWG FastView has no way to access iCloud files. The local file option only seems to work with files downloaded from their cloud. So I went to their website using Safari on my Mac and tried to upload that way. It said I needed Flash to upload. No modern system should require Flash to operate."

## 5. Free Features Moved Behind Subscription Paywall

### Symptom

After updating DWG FastView, previously free features are now behind a paywall. Text/object move, rotate, scaling, and text editing are now paid-only features. Export to PDF is now a paid feature. Measurements require a subscription. The user can't revert to the previous version.

### Root Cause

DWG FastView changed its business model, moving previously free features to premium subscriptions. "Recent update made text/object move, rotate, scaling, etc. a paid feature." The subscription model (Premium or Super) is required for advanced editing, cloud storage, batch processing, and export features. Users who relied on the free version are affected.

### Fix

1. **Evaluate premium subscription**:
   - "Unlock advanced editing, cloud storage, batch processing & more with a Premium or Super subscription"
   - If you use DWG FastView regularly, the subscription may be worth it
   - Compare with alternative apps' pricing
   - Check if the features you need are in Premium or Super tier

2. **Use remaining free features**:
   - "Core viewing and editing features are completely free"
   - Basic viewing, zooming, panning remain free
   - Layer management (on/off, freeze, isolate) is free
   - Text search is free

3. **Use alternative free CAD viewers**:
   - AutoCAD mobile app (free for Autodesk subscribers)
   - Autodesk DWG TrueView (PC only, free)
   - LibreCAD (PC, free, open source)
   - Onshape (cloud-based, free tier)

4. **Contact support about subscription issues**:
   - "They accepted my payment, but never sent an email with confirmation"
   - "No way to contact them, or call"
   - Email: support.mc@gstarcad.net
   - Report payment issues and request confirmation

5. **Don't update if current version works**:
   - If your current version has the features you need for free
   - Don't update to newer versions
   - Disable automatic updates for the app
   - This preserves your current feature set

6. **Check for standalone purchase option**:
   - "They used to sell a standalone app"
   - "I would pay a reasonable fee for an app, but I will not do a subscription"
   - Contact support to ask about perpetual license options
   - Or look for older versions with standalone pricing

### Community Report

> "Why did you make text/object move, rotate, scaling, etc. also text editing all that is now only a paid feature? All those basic features were always free. You just ruined the application feeling pretty much useless. The export to PDF is now a paid only feature. I used to find it fairly useful, but not $47 a year, every year, useful. They used to sell a standalone app."

## 6. Additional DWG FastView Issues

### Excessive Advertisements

**Issue**: "So many advertisements that it becomes unusable. Multiple banners on a single page, popups, timed video ad screens."
**Fix**: "Intractable Splash Ads Have Been Removed! Now only basic ads and never affect users' operations." Update to the latest version. Consider premium subscription to remove ads entirely.

### 2D Wireframe Only for 3D Models

**Issue**: "2D wireframe being the only option to view the model. No ability to view conceptually/hidden."
**Fix**: This is a limitation of the free version. Premium subscription includes 3D model viewer with 40+ formats, rotate, section, explode view. Or use a dedicated 3D viewer.

### PDF Files Not Displaying

**Issue**: "All it would display were jpg's. None of my pdf's would populate."
**Fix**: DWG FastView is primarily for DWG/DXF files. For PDF viewing, use a PDF reader. To convert PDF to DWG, use the "Convert PDF back to DWG" feature (premium).

### App Not Working After Update

**Issue**: "After update to newest version it won't open any files. Even ones it opened before."
**Fix**: "They fixed the big old bug and it's working great." Update to the latest patched version. If still not working, uninstall and reinstall. Contact support with device info.
