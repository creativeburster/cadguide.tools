# Glovius Getting Started Guide: Setup, Key Features, and Workflow Overview

Mobile 3D CAD file viewer for viewing and analyzing 3D models.

## Overview

Glovius is a 3d modeling tool developed in India. It is available on Android, iOS with a Freemium pricing model starting at Free. The current version is 2025.

## Key Capabilities

- **Category**: 3D Modeling
- **Geometry Engine**: HCL Glovius Engine
- **Supported Standards**: CATIA, NX, SolidWorks, Creo, Inventor
- **Platforms**: Android, iOS
- **Pricing**: Freemium (from Free)
- **Country of Origin**: India

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Android, iOS and meets the minimum hardware specifications for 3d modeling workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Glovius and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (CATIA, NX, SolidWorks, Creo, Inventor) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Glovius's core 3d modeling capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Glovius uses a Freemium pricing model with a starting price of Free. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Glovius supports the following industry-standard formats: CATIA, NX, SolidWorks, Creo, Inventor. This ensures interoperability with other tools in the 3D Modeling ecosystem.

## Summary

Glovius provides 3d modeling capabilities with HCL Glovius Engine under the hood, running on Android, iOS. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
