# 3Design Getting Started Guide: Setup, Key Features, and Workflow Overview

Parametric 3D CAD for professional jewelry.

## Overview

3Design is a specialized tool developed in USA. It is available on Windows, macOS with a Perpetual pricing model starting at $6000. The current version is 2024.

## Key Capabilities

- **Category**: Specialized
- **Geometry Engine**: Proprietary Parametric
- **Supported Standards**: STL, OBJ, 3DM
- **Platforms**: Windows, macOS
- **Pricing**: Perpetual (from $6000)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows, macOS and meets the minimum hardware specifications for specialized workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch 3Design and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (STL, OBJ, 3DM) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage 3Design's core specialized capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

3Design uses a Perpetual pricing model with a starting price of $6000. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

3Design supports the following industry-standard formats: STL, OBJ, 3DM. This ensures interoperability with other tools in the Specialized ecosystem.

## Summary

3Design provides specialized capabilities with Proprietary Parametric under the hood, running on Windows, macOS. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
