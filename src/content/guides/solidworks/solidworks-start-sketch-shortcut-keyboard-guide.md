# SolidWorks Start Sketch Shortcut and Essential Keyboard Commands Guide

If you're coming from AutoCAD or another CAD program, one of the first things you'll look for in SolidWorks is a keyboard shortcut to start a sketch. The answer that trips up most new users: **there isn't one by default**. SolidWorks doesn't assign a keyboard shortcut to the "Start Sketch" command out of the box. But you can set one up in about 30 seconds, and once you do, it'll change your workflow.

## The S Key: SolidWorks' Super Shortcut

Before we get to setting up a Start Sketch shortcut, you need to understand the S key — it's the most important shortcut in SolidWorks.

Press the **S key** anywhere in SolidWorks and a context-sensitive shortcut toolbar pops up at your cursor position. The toolbar changes depending on what you're doing:

- **In a part file (not editing a sketch):** Shows commands like Extrude, Revolve, Loft, Sweep, Fillet
- **While editing a sketch:** Shows Sketch tools — Line, Rectangle, Circle, Trim, Dimension, Extrude
- **In an assembly:** Shows assembly-specific commands — Mate, Insert Component, Exploded View
- **In a drawing:** Shows drawing tools — Smart Dimension, View, Annotation

The beauty of the S-key toolbar is that it's **fully customizable**. You can add any command to any of the four contexts. Most experienced SolidWorks users have heavily customized S-key toolbars with their most-used commands.

## How to Set Up a Start Sketch Keyboard Shortcut

Since there's no default key for starting a sketch, here's how to assign one:

1. Go to **Tools → Customize** (or right-click any toolbar and select Customize)
2. Switch to the **Keyboard** tab
3. In the search box, type "Sketch"
4. Find the command named **"Sketch"** (this is the Start Sketch command)
5. Click in the **Shortcut** column next to it
6. Press the key combination you want to assign (we recommend `Shift+S` or just `S` if you prefer direct access over the toolbar)
7. Click **OK** to save

**Our recommendation:** Don't assign a single key to Start Sketch — it conflicts with the S-key toolbar. Instead, add "Sketch" to your S-key toolbar:

1. Go to **Tools → Customize**
2. Switch to the **Commands** tab
3. Find the **Sketch** category
4. Drag the **Sketch** command onto the S-key toolbar (press S to show it first, then drag the command onto it while the Customize dialog is open)
5. Click OK

Now when you press S, the Start Sketch command is right there at your cursor. One press of S, one click, and you're sketching.

## Mouse Gestures

SolidWorks also supports mouse gestures — quick flicks of the right mouse button in a direction to trigger commands. Many users prefer these over keyboard shortcuts because they keep your hand on the mouse.

**To enable and customize mouse gestures:**
1. Go to **Tools → Customize → Mouse Gestures** tab
2. Check **Enable mouse gestures**
3. Choose 4 gestures or 8 gestures (8 gives more options but requires more precision)
4. Assign commands to each direction

**Default 4-gesture assignments (part mode):**
- **Up:** Extrude
- **Right:** Sketch
- **Down:** Fillet
- **Left:** Cancel

With 8 gestures, you get additional directions for Revolve, Loft, Shell, and more. The gesture guide appears as a circular overlay when you hold the right mouse button — flick in the direction of the command you want.

## The "No Default Sketch Shortcut" Question

To directly answer the question that brings most people to this guide: **"What is the keyboard shortcut for start sketch in SolidWorks?"**

There is no default keyboard shortcut for the Start Sketch command. You have three options:

1. **Add it to the S-key toolbar** (recommended — press S, click Sketch)
2. **Assign a custom keyboard shortcut** via Tools → Customize → Keyboard
3. **Use a mouse gesture** (right-click flick up, if assigned to Sketch)

Most SolidWorks power users go with option 1. The S-key toolbar is always one keypress away, and you can pack it with all your frequently used commands. It's faster than memorizing dozens of individual keyboard shortcuts.

## Pro Tips

- **Ctrl+Q vs Ctrl+B:** Use Ctrl+Q (force rebuild) when something looks wrong in the graphics area. It's a deeper rebuild than Ctrl+B and fixes most display glitches.
- **Q key for planes:** When you need to select a reference plane but can't see it, hold Q to temporarily show all planes. Release Q and they hide again.
- **R key for recent files:** Press R for a flyout of recently opened files — faster than File → Open.
- **G key for magnifier:** When you need to select a tiny edge or vertex, press G to bring up a magnified window at your cursor. It's like a magnifying glass for your model.
- **Customize per project:** You can save different customization profiles for different types of work. Export your customizations via Tools → Customize → Save Settings, then load them when switching projects.

Learning these shortcuts takes a few days of conscious effort. After a week, they become muscle memory, and you'll wonder how you ever modeled without them.
