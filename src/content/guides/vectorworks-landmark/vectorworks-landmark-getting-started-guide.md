# Vectorworks Landmark Getting Started Guide: Setup, Key Features, and Workflow Overview

The premier CAD software for landscape design.

## Overview

Vectorworks Landmark is a bim tool developed in USA. It is available on Windows, macOS with a Subscription pricing model starting at $153. The current version is 2025.

## Key Capabilities

- **Category**: BIM
- **Geometry Engine**: Parasolid
- **Supported Standards**: IFC, DWG, Shapefile
- **Platforms**: Windows, macOS
- **Pricing**: Subscription (from $153)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows, macOS and meets the minimum hardware specifications for bim workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Vectorworks Landmark and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (IFC, DWG, Shapefile) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Vectorworks Landmark's core bim capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Vectorworks Landmark uses a Subscription pricing model with a starting price of $153. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Vectorworks Landmark supports the following industry-standard formats: IFC, DWG, Shapefile. This ensures interoperability with other tools in the BIM ecosystem.

## Summary

Vectorworks Landmark provides bim capabilities with Parasolid under the hood, running on Windows, macOS. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
