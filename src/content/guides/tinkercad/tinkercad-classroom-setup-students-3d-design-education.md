# Tinkercad Classroom: Setting Up 3D Design Classes for Students

I teach 3D design to middle and high school students using Tinkercad. It's the best tool for education — free, browser-based, and safe for students under 13 (with teacher moderation). Here's how to set up a classroom.

## Step 1: Create a Teacher Account

1. Go to **tinkercad.com** → **Sign Up** → select **Teacher** account type.
2. Verify your educator status (school email or documentation).
3. Once approved, you get access to:
   - **Classrooms**: Manage multiple classes
   - **Student accounts**: Create accounts for students without email
   - **Assignments**: Create and distribute projects
   - **Gallery**: View and share student work

## Step 2: Create a Class

1. Click **Classes** (left sidebar) → **Create New Class**.
2. Enter:
   - **Class name**: "8th Grade 3D Design"
   - **Subject**: STEM / Technology / Art
   - **Grade level**: Middle School / High School
   - **Class description**: Brief description for students

3. Tinkercad generates a **class code** and **class link**.
4. Students join the class using the code or link.

## Step 3: Add Students

### Option A: Student-Managed Accounts (13+)

1. Share the class code with students.
2. Students create their own Tinkercad accounts using their email.
3. They enter the class code to join.
4. Their projects appear in your class gallery.

### Option B: Teacher-Managed Accounts (Under 13)

1. In the class: click **Add Students**.
2. Enter student names (first name + last initial, e.g., "John S.").
3. Tinkercad creates accounts without requiring student email.
4. Each student gets a nickname and password.
5. Distribute login credentials to students.

6. Benefits:
   - No student email required (COPPA compliant)
   - Teacher controls all accounts
   - Student data is protected
   - Students can't access public Tinkercad community

## Step 4: Create Assignments

1. In the class: click **Create Assignment**.
2. Set:
   - **Assignment title**: "Name Tag Project"
   - **Instructions**: Step-by-step description of the project
   - **Due date**: When the project is due
   - **Template**: Optional — start with a pre-made model for students to modify
   - **Requirements**: e.g., "Must include text, a hole, and be under 60×20mm"

3. Click **Publish** — the assignment appears in all students' dashboards.

### Assignment Ideas by Grade Level

**Elementary (Grades 3-5)**:
- Name tag with text and a hole
- Simple house (box + roof prism)
- Animal figure using basic shapes
- Keychain with a custom shape

**Middle School (Grades 6-8)**:
- Phone stand with angled support
- pencil holder with multiple compartments
- Simple gear (using shape generator)
- Bridge model (truss structure)

**High School (Grades 9-12)**:
- Mechanical part with specific dimensions
- Architectural model of a building
- Product design prototype (iterative design process)
- 3D-printable enclosure for an Arduino project

## Step 5: Monitor Student Progress

1. In the class: click **Gallery**.
2. View all student projects:
   - Thumbnail of each model
   - Student name
   - Last modified date
   - Assignment status (Submitted / In Progress / Not Started)

3. Click on a project to view it in 3D:
   - Rotate, zoom, and inspect the model
   - Check dimensions and design quality
   - Leave feedback comments

4. Track participation:
   - **Activity log**: Shows when each student was last active
   - **Project count**: Number of projects per student
   - **Time spent**: Approximate time spent modeling

## Step 6: Provide Feedback

1. Open a student's project.
2. Click **Comment** → type feedback:
   - "Great use of the hole tool! Try making the text bigger."
   - "The dimensions are correct. Consider adding a fillet to the corners."
   - "The model is too tall for printing — reduce the height to under 20mm."

3. Students see comments when they open their project.
4. They can revise and resubmit.

## Step 7: Share and Showcase

### Class Gallery

1. Set the class gallery to **Shared** (visible to class members) or **Public** (visible to anyone with the link).
2. Students can view each other's work and leave comments.
3. This creates a collaborative learning environment.

### Export for 3D Printing

1. Select student projects to print.
2. Export each as STL.
3. Print on the school's 3D printer(s).
4. Students get physical feedback on their designs — this is the most rewarding part of the class.

### Share with Parents

1. Set the gallery to **Public**.
2. Share the gallery link with parents via email or newsletter.
3. Parents can view their child's work without a Tinkercad account.

## Lesson Plan Structure

### Week 1: Introduction to Tinkercad
- Interface tour (15 min)
- Navigation practice (15 min)
- First model: simple box with a hole (20 min)

### Week 2: Shape Manipulation
- Resize, rotate, and move shapes (15 min)
- Group and ungroup (15 min)
- Project: name tag (20 min)

### Week 3: The Hole Tool
- Creating holes and cutouts (15 min)
- Combining solids and holes (15 min)
- Project: picture frame with a cutout (20 min)

### Week 4: Text and Customization
- Adding text to models (10 min)
- Shape generators (15 min)
- Project: custom keychain (25 min)

### Week 5: Precision and Measurement
- Ruler tool (15 min)
- Dimension accuracy (15 min)
- Project: phone stand with specific dimensions (20 min)

### Week 6: Final Project
- Design challenge: "Design a useful object for your desk"
- Students work independently
- Teacher provides individual feedback
- Final showcase and 3D printing

## Tips for Teaching with Tinkercad

1. **Demo on a projector**: Model the steps live while students follow along.
2. **Keep projects small**: 30-minute projects keep students engaged. Longer projects lose attention.
3. **Print the best projects**: 3D printing makes the digital work tangible and rewarding.
4. **Encourage iteration**: Let students revise their designs after seeing the printed result.
5. **Don't over-teach**: Tinkercad is intuitive. Let students explore and discover features on their own.
6. **Have a backup plan**: If the internet is down, have paper sketching exercises ready.
