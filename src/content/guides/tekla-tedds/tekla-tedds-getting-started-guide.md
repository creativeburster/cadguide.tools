# Tekla Tedds Getting Started Guide: Setup, Key Features, and Workflow Overview

Trimble Tekla Tedds — calculation library and document generator for structural design.

## Overview

Tekla Tedds is a cae/cam tool developed in USA. It is available on Windows with a Subscription pricing model starting at $2400. The current version is 2024.

## Key Capabilities

- **Category**: CAE/CAM
- **Geometry Engine**: Tedds calculation engine
- **Supported Standards**: AISC, ACI, Eurocode, BS, AS
- **Platforms**: Windows
- **Pricing**: Subscription (from $2400)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for cae/cam workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Tekla Tedds and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (AISC, ACI, Eurocode, BS, AS) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Tekla Tedds's core cae/cam capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Tekla Tedds uses a Subscription pricing model with a starting price of $2400. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Tekla Tedds supports the following industry-standard formats: AISC, ACI, Eurocode, BS, AS. This ensures interoperability with other tools in the CAE/CAM ecosystem.

Tekla Tedds provides cae/cam capabilities with Tedds calculation engine under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
