# PADS Professional Getting Started Guide: Setup, Key Features, and Workflow Overview

Siemens EDA's comprehensive PCB design solution for mid-to-high complexity designs with advanced simulation and analysis capabilities.

## Overview

PADS Professional is a eda tool developed in USA. It is available on Windows with a Subscription pricing model starting at $8000. The current version is VX.4.

## Key Capabilities

- **Category**: EDA
- **Geometry Engine**: PADS Platform
- **Supported Standards**: IPC, IEEE, JEDEC
- **Platforms**: Windows
- **Pricing**: Subscription (from $8000)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for eda workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch PADS Professional and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (IPC, IEEE, JEDEC) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage PADS Professional's core eda capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

PADS Professional uses a Subscription pricing model with a starting price of $8000. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

PADS Professional supports the following industry-standard formats: IPC, IEEE, JEDEC. This ensures interoperability with other tools in the EDA ecosystem.

## Summary

PADS Professional provides eda capabilities with PADS Platform under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
