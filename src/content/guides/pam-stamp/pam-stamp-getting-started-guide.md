# PAM-STAMP Getting Started Guide: Setup, Key Features, and Workflow Overview

ESI Group's sheet metal forming simulation software using finite element analysis for stamping process optimization and spring back compensation.

## Overview

PAM-STAMP is a cae/cam tool developed in France. It is available on Windows with a Perpetual pricing model starting at Free. The current version is 2025.

## Key Capabilities

- **Category**: CAE/CAM
- **Geometry Engine**: PAM-STAMP FEA Engine
- **Supported Standards**: STEP, IGES, VDA
- **Platforms**: Windows
- **Pricing**: Perpetual (from Free)
- **Country of Origin**: France

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for cae/cam workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch PAM-STAMP and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (STEP, IGES, VDA) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage PAM-STAMP's core cae/cam capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

PAM-STAMP uses a Perpetual pricing model with a starting price of Free. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

PAM-STAMP supports the following industry-standard formats: STEP, IGES, VDA. This ensures interoperability with other tools in the CAE/CAM ecosystem.

## Summary

PAM-STAMP provides cae/cam capabilities with PAM-STAMP FEA Engine under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
