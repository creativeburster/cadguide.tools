# Updraw Getting Started Guide: Setup, Key Features, and Workflow Overview

Mobile 2D CAD drawing application with dimension tools.

## Overview

Updraw is a 2d cad tool developed in USA. It is available on iOS with a Freemium pricing model starting at Free. The current version is 2024.

## Key Capabilities

- **Category**: 2D CAD
- **Geometry Engine**: Updraw Mobile Engine
- **Supported Standards**: DWG, PDF
- **Platforms**: iOS
- **Pricing**: Freemium (from Free)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs iOS and meets the minimum hardware specifications for 2d cad workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Updraw and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (DWG, PDF) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Updraw's core 2d cad capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Updraw uses a Freemium pricing model with a starting price of Free. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Updraw supports the following industry-standard formats: DWG, PDF. This ensures interoperability with other tools in the 2D CAD ecosystem.

## Summary

Updraw provides 2d cad capabilities with Updraw Mobile Engine under the hood, running on iOS. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
