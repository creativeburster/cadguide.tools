# DDS-CAD Getting Started Guide: Setup, Key Features, and Workflow Overview

MEP design and BIM software for mechanical, electrical, and plumbing engineering.

## Overview

DDS-CAD is a bim tool developed in Norway. It is available on Windows with a Perpetual pricing model starting at $2500. The current version is 2025.

## Key Capabilities

- **Category**: BIM
- **Geometry Engine**: DDS-CAD Engine
- **Supported Standards**: IFC, DWG, DXF, RVT
- **Platforms**: Windows
- **Pricing**: Perpetual (from $2500)
- **Country of Origin**: Norway

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for bim workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch DDS-CAD and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (IFC, DWG, DXF, RVT) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage DDS-CAD's core bim capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

DDS-CAD uses a Perpetual pricing model with a starting price of $2500. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

DDS-CAD supports the following industry-standard formats: IFC, DWG, DXF, RVT. This ensures interoperability with other tools in the BIM ecosystem.

## Summary

DDS-CAD provides bim capabilities with DDS-CAD Engine under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
