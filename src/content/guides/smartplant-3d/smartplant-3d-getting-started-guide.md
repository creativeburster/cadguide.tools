# Hexagon SmartPlant 3D Getting Started Guide: Setup, Key Features, and Workflow Overview

Hexagon's data-centric plant-design platform (now part of CADWorx & Analysis Solutions).

## Overview

Hexagon SmartPlant 3D is a bim tool developed in USA. It is available on Windows with a Subscription pricing model starting at $18000. The current version is 2024.

## Key Capabilities

- **Category**: BIM
- **Geometry Engine**: SP3D (database-centric)
- **Supported Standards**: ISO 15926, PCF, DGN
- **Platforms**: Windows
- **Pricing**: Subscription (from $18000)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for bim workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Hexagon SmartPlant 3D and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (ISO 15926, PCF, DGN) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Hexagon SmartPlant 3D's core bim capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Hexagon SmartPlant 3D uses a Subscription pricing model with a starting price of $18000. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Hexagon SmartPlant 3D supports the following industry-standard formats: ISO 15926, PCF, DGN. This ensures interoperability with other tools in the BIM ecosystem.

## Summary

Hexagon SmartPlant 3D provides bim capabilities with SP3D (database-centric) under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
