# MSC Patran Getting Started Guide: Setup, Key Features, and Workflow Overview

Long-standing FEA preprocessor and post-processor from Hexagon/MSC, tightly paired with MSC Nastran.

## Overview

MSC Patran is a cae/cam tool developed in USA. It is available on Windows, Linux with a Subscription pricing model starting at $14000. The current version is 2024.

## Key Capabilities

- **Category**: CAE/CAM
- **Geometry Engine**: Patran GUI + Nastran/Marc/Abaqus
- **Supported Standards**: Nastran .bdf, STEP, IGES
- **Platforms**: Windows, Linux
- **Pricing**: Subscription (from $14000)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows, Linux and meets the minimum hardware specifications for cae/cam workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch MSC Patran and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (Nastran .bdf, STEP, IGES) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage MSC Patran's core cae/cam capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

MSC Patran uses a Subscription pricing model with a starting price of $14000. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

MSC Patran supports the following industry-standard formats: Nastran .bdf, STEP, IGES. This ensures interoperability with other tools in the CAE/CAM ecosystem.

## Summary

MSC Patran provides cae/cam capabilities with Patran GUI + Nastran/Marc/Abaqus under the hood, running on Windows, Linux. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
