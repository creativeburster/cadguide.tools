# Renga Getting Started Guide: Setup, Key Features, and Workflow Overview

Russian BIM system for collaborative architectural design, structural engineering, MEP, and building technology.

## Overview

Renga is a bim tool developed in Russia. It is available on Windows with a Perpetual pricing model starting at $2500. The current version is 2024.

## Key Capabilities

- **Category**: BIM
- **Geometry Engine**: Renga Engine
- **Supported Standards**: IFC, DWG, DXF, RVT
- **Platforms**: Windows
- **Pricing**: Perpetual (from $2500)
- **Country of Origin**: Russia

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for bim workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Renga and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (IFC, DWG, DXF, RVT) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Renga's core bim capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Renga uses a Perpetual pricing model with a starting price of $2500. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Renga supports the following industry-standard formats: IFC, DWG, DXF, RVT. This ensures interoperability with other tools in the BIM ecosystem.

## Summary

Renga provides bim capabilities with Renga Engine under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
