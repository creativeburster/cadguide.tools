# Shoemaster Getting Started Guide: Setup, Key Features, and Workflow Overview

Leading CAD/CAM for the global footwear industry.

## Overview

Shoemaster is a specialized tool developed in USA. It is available on Windows with a Perpetual pricing model starting at $5000. The current version is 2024.

## Key Capabilities

- **Category**: Specialized
- **Geometry Engine**: Proprietary
- **Supported Standards**: DXF, STL
- **Platforms**: Windows
- **Pricing**: Perpetual (from $5000)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for specialized workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Shoemaster and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (DXF, STL) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Shoemaster's core specialized capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
