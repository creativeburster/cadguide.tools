# Edificius Getting Started Guide: Setup, Key Features, and Workflow Overview

BIM software with the highest number of IFC certified solutions for architecture, engineering, and construction.

## Overview

Edificius is a bim tool developed in Italy. It is available on Windows with a Perpetual pricing model starting at $2000. The current version is 2025.

## Key Capabilities

- **Category**: BIM
- **Geometry Engine**: Edificius Engine
- **Supported Standards**: IFC, DWG, DXF, RVT
- **Platforms**: Windows
- **Pricing**: Perpetual (from $2000)
- **Country of Origin**: Italy

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for bim workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Edificius and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (IFC, DWG, DXF, RVT) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Edificius's core bim capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Edificius uses a Perpetual pricing model with a starting price of $2000. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Edificius supports the following industry-standard formats: IFC, DWG, DXF, RVT. This ensures interoperability with other tools in the BIM ecosystem.

## Summary

Edificius provides bim capabilities with Edificius Engine under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
