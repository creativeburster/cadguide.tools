# SolveSpace Pro Getting Started Guide: Setup, Key Features, and Workflow Overview

Constraint-based 2D/3D parametric CAD.

## Overview

SolveSpace Pro is a 3d modeling tool developed in USA. It is available on Windows, macOS, Linux with a Free pricing model starting at Free. The current version is 3.1.

## Key Capabilities

- **Category**: 3D Modeling
- **Geometry Engine**: Custom
- **Supported Standards**: STEP, STL, DXF
- **Platforms**: Windows, macOS, Linux
- **Pricing**: Free (from Free)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows, macOS, Linux and meets the minimum hardware specifications for 3d modeling workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch SolveSpace Pro and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (STEP, STL, DXF) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage SolveSpace Pro's core 3d modeling capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.
