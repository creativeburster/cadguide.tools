# Solid Edge Viewer Getting Started Guide: Setup, Key Features, and Workflow Overview

Free viewer for Solid Edge and 2D CAD files.

## Overview

Solid Edge Viewer is a viewer tool developed in USA. It is available on Windows with a Free pricing model starting at Free. The current version is 2024.

## Key Capabilities

- **Category**: Viewer
- **Geometry Engine**: Siemens JT
- **Supported Standards**: PAR, ASM, DWG
- **Platforms**: Windows
- **Pricing**: Free (from Free)
- **Country of Origin**: USA

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows and meets the minimum hardware specifications for viewer workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch Solid Edge Viewer and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (PAR, ASM, DWG) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage Solid Edge Viewer's core viewer capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

Solid Edge Viewer uses a Free pricing model with a starting price of Free. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

Solid Edge Viewer supports the following industry-standard formats: PAR, ASM, DWG. This ensures interoperability with other tools in the Viewer ecosystem.

## Summary

Solid Edge Viewer provides viewer capabilities with Siemens JT under the hood, running on Windows. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
