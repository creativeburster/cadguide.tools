# Rhino to STL/OBJ Export: Optimal Mesh Settings for 3D Printing and Rendering

I've been running a 3D printing service for three years, and about 40% of the files customers send me are STLs exported from Rhino. The quality ranges from perfect to unprintable, and the difference is almost always in the mesh export settings. Rhino's default STL export settings produce meshes that are either too dense (500MB+ files that crash slicer software) or too coarse (visible facets on curved surfaces). I'll share the exact settings I use for different applications, from high-resolution resin printing to architectural rendering.

## Understanding Rhino's Mesh System

Rhino uses two types of meshes:

1. **Render meshes**: Automatically generated by Rhino for display purposes. These are what you see in the viewport.
2. **Export meshes**: Generated when you export to STL or OBJ. These are independent of render meshes.

The render mesh settings (Tools → Options → Mesh) control what you see in the viewport. The export mesh settings (in the STL/OBJ export dialog) control what goes into the exported file. They're separate settings, and optimizing one doesn't optimize the other.

## STL Export Settings for 3D Printing

### For Resin Printing (SLA/DLP) — High Detail

Resin printers can resolve details down to 25 microns, so the STL needs to be fine enough that facets aren't visible.

1. Select the object(s) to export
2. **File → Export Selected → STL**
3. In the STL Mesh Export dialog, set:
   - **Tolerance**: 0.001 mm (or 0.0005 for jewelry)
   - **Max angle between adjacent facets**: 15 degrees
   - **Max aspect ratio**: 4
   - **Max edge length**: 0 (unlimited — let the angle control the density)
   - **Min edge length**: 0.0001
   - **Max distance edge to surface**: 0.001 mm
4. Check **Refine mesh** and **Weld vertices**
5. Click **OK** and save

For a typical jewelry ring (20mm diameter), this produces a file of 5-15MB — manageable for slicer software and detailed enough for resin printing at 25-micron layer height.

### For FDM Printing — Medium Detail

FDM printers have layer lines that mask minor faceting, so the mesh can be coarser:

1. Same export dialog, set:
   - **Tolerance**: 0.01 mm
   - **Max angle between adjacent facets**: 20 degrees
   - **Max aspect ratio**: 6
   - **Max edge length**: 0
   - **Min edge length**: 0.001
   - **Max distance edge to surface**: 0.01 mm
2. Check **Refine mesh** and **Weld vertices**

For a typical mechanical part (50mm), this produces a file of 2-10MB.

### For Large Format Printing (1m+) — Low Detail

Large prints are viewed from a distance, so faceting is invisible:

1. Set:
   - **Tolerance**: 0.1 mm
   - **Max angle between adjacent facets**: 30 degrees
   - **Max aspect ratio**: 10
   - **Max edge length**: 0
   - **Min edge length**: 0.01
   - **Max distance edge to surface**: 0.1 mm

## OBJ Export Settings for Rendering

For rendering in V-Ray, KeyShot, or Blender, the mesh needs to be smooth but not excessively dense. The renderer will apply smoothing groups, so the mesh doesn't need to be as fine as a 3D printing mesh.

1. Select the object(s) to export
2. **File → Export Selected → OBJ**
3. In the OBJ Export dialog:
   - **Tolerance**: 0.01 mm
   - **Max angle**: 15 degrees
   - **Max aspect ratio**: 6
   - Check **Export normals** (critical for smooth shading)
   - Check **Export texture coordinates** (if the object has materials)
   - Check **Weld vertices**
   - Set **Y up** (for Blender) or **Z up** (for V-Ray for Rhino)

## Pre-Export Cleanup

Before exporting, always clean up the geometry. Bad geometry produces bad exports.

### Check for Open Meshes

1. Run `CheckMesh` on the object
2. Look for:
   - **Open edges**: The mesh has holes — fix with `FillMeshHoles`
   - **Non-manifold edges**: More than two faces share an edge — fix with `NonmanifoldMerge` then `FillMeshHoles`
   - **Duplicate faces**: Two faces occupy the same position — fix with `DupMeshHoles` or delete manually

### Merge Naked Edges

If your object is a polysurface (not a single solid), the edges where surfaces meet may be "naked" (open):

1. Run `ShowEdges`
2. Naked edges appear in red
3. Run `MergeEdge` to merge adjacent edges
4. Or run `JoinMesh` to merge all naked edges at once

### Remove Naked Micro-Edges

Tiny edges (less than 0.001mm) can cause slicer software to fail:

1. Run `RemoveNakedMicroEdges`
2. This removes edges that are too small to be meaningful
3. Re-run `CheckMesh` to verify

### Reduce Mesh If Too Dense

If your exported STL is too large (500MB+), reduce it:

1. Run `ReduceMesh`
2. Set the target percentage — 50% is a good starting point
3. Check the result visually — if facets are visible, undo and try 70%
4. Re-export

## Common Export Problems

### "STL file is too large for slicer"

**Cause**: Mesh is too dense
**Fix**: Use `ReduceMesh` to reduce by 50-70%, or use coarser export settings

### "Slicer reports non-manifold geometry"

**Cause**: The mesh has edges shared by more than two faces
**Fix**: Run `CheckMesh`, identify non-manifold edges, use `NonmanifoldMerge` to fix

### "Printed part has visible facets on curved surfaces"

**Cause**: Mesh angle too high (coarse mesh)
**Fix**: Re-export with max angle of 10-15 degrees instead of 20-30

### "OBJ import in Blender has no smoothing"

**Cause**: Normals not exported
**Fix**: In the OBJ export dialog, check **Export normals**. Blender uses normals to apply smooth shading

### "STL file has incorrect scale"

**Cause**: Rhino model units don't match the STL export units
**Fix**: In the STL export dialog, check the **Units** setting. If your model is in millimeters, export in millimeters. Most slicer software expects millimeters.

## Batch Export Multiple Objects

If you need to export many objects as separate STL files:

1. Select all objects
2. **File → Export Selected → STL**
3. In the dialog, check **Export each object as a separate file**
4. Choose a destination folder
5. Rhino will create one STL per object, named after the object name

For programmatic batch export, use this Python script:

```python
import rhinoscriptsyntax as rs
import scriptcontext as sc
import Rhino

def export_all_as_stl():
    objects = rs.ObjectsByType(16)  # 16 = polysurfaces
    if not objects:
        print("No polysurfaces found")
        return
    
    folder = rs.BrowseForFolder(message="Select export folder")
    if not folder:
        return
    
    for obj_id in objects:
        name = rs.ObjectName(obj_id)
        if not name:
            name = f"object_{obj_id}"
        
        filepath = f"{folder}\\{name}.stl"
        
        # Export settings
        settings = Rhino.FileIO.StlFileOptions()
        settings.AngularTolerance = 15.0  # degrees
        settings.LinearTolerance = 0.01   # mm
        settings.Refine = True
        settings.WeldVertices = True
        
        # Export
        success = Rhino.RhinoDoc.ActiveDoc.WriteFile(
            filepath, settings
        )
        
        if success:
            print(f"Exported: {name}.stl")
        else:
            print(f"FAILED: {name}")

if __name__ == '__main__':
    export_all_as_stl()
```

Always run `CheckMesh` before exporting, and always test-print a small sample when using new export settings for the first time. The 5 minutes you spend checking the mesh will save you hours of failed prints.
