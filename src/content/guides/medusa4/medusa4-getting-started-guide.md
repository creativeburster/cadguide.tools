# MEDUSA4 Getting Started Guide: Setup, Key Features, and Workflow Overview

Intelligent 2D & 3D CAD software for mechanical engineering, factory layout, and plant design with AR/VR capabilities.

## Overview

MEDUSA4 is a 2d cad tool developed in Germany. It is available on Windows, Linux with a Perpetual pricing model starting at $3000. The current version is 2024.

## Key Capabilities

- **Category**: 2D CAD
- **Geometry Engine**: MEDUSA4 Engine
- **Supported Standards**: DWG, DXF, PDF, STEP
- **Platforms**: Windows, Linux
- **Pricing**: Perpetual (from $3000)
- **Country of Origin**: Germany

## Installation and Setup

1. **Check System Requirements**: Ensure your system runs Windows, Linux and meets the minimum hardware specifications for 2d cad workloads.
2. **Obtain a License**: Visit the official website to purchase or request a trial license.
3. **Download and Install**: Download the installer from the vendor's official site and follow the platform-specific installation instructions.
4. **Activate**: Launch MEDUSA4 and enter your license credentials to activate the software.

## Recommended Workflow

1. **Start a New Project**: Create a new file using the appropriate template for your design type.
2. **Import or Create Geometry**: Use the supported file formats (DWG, DXF, PDF, STEP) to import existing models or create new geometry from scratch.
3. **Apply Design Tools**: Leverage MEDUSA4's core 2d cad capabilities to develop your design.
4. **Review and Validate**: Use built-in validation tools to check for errors and ensure compliance with industry standards.
5. **Export and Share**: Export your work in the appropriate format for downstream consumption.

## Pricing and Licensing

MEDUSA4 uses a Perpetual pricing model with a starting price of $3000. Depending on your organization's size and needs, volume licensing and educational discounts may be available — contact the vendor for a tailored quote.

## File Format Support

MEDUSA4 supports the following industry-standard formats: DWG, DXF, PDF, STEP. This ensures interoperability with other tools in the 2D CAD ecosystem.

## Summary

MEDUSA4 provides 2d cad capabilities with MEDUSA4 Engine under the hood, running on Windows, Linux. Whether you are evaluating it for purchase or getting started with a new license, this guide covers the essentials to begin productive work.
