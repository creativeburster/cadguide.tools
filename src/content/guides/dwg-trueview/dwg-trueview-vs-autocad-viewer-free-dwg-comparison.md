# DWG TrueView vs AutoCAD Viewer: Free DWG Viewing Options Compared

There are several free options for viewing DWG files. We've tested all the major ones. DWG TrueView is the most capable, but it's not always the best choice. Here's our comparison.

## Options Compared

1. **DWG TrueView**: Autodesk's free desktop DWG viewer (Windows only)
2. **Autodesk Online Viewer**: Browser-based viewer at viewer.autodesk.com
3. **AutoCAD Web**: Free web-based AutoCAD with viewing and limited editing
4. **Third-party viewers**: eDrawings, Bentley View, LibreCAD (for DXF)

## Feature Comparison

| Feature | DWG TrueView | Autodesk Online Viewer | AutoCAD Web |
|---------|-------------|----------------------|-------------|
| Platform | Windows desktop | Browser (any OS) | Browser (any OS) |
| Installation | Required (~700MB) | None | None |
| DWG support | All versions | All versions | All versions |
| File size limit | Unlimited | 200MB | 50MB |
| Measurement | Full | Full | Full |
| Printing/Plotting | Full (batch) | Basic (single) | Basic (single) |
| Layer control | Full | Full | Full |
| 3D viewing | Yes (ViewCube) | Yes (excellent) | Limited |
| DWG Convert | Yes (batch) | No | No |
| DWG Compare | Yes | No | No |
| Markup | Via Design Review | Yes (cloud marks) | Yes (basic) |
| Offline use | Yes | No | No |
| Cost | Free | Free (Autodesk account) | Free (limited) |

## DWG TrueView (Desktop)

### Pros
- **Full DWG compatibility**: Opens any DWG version without conversion
- **No file size limits**: Handles 100MB+ drawings
- **Batch conversion**: Convert DWG versions in bulk
- **DWG Compare**: Compare two drawings visually
- **Batch plotting**: Print multiple drawings at once
- **Offline**: Works without internet
- **AutoCAD engine**: Same rendering engine as AutoCAD — drawings look exactly as intended

### Cons
- **Windows only**: No Mac or Linux version
- **Large installation**: ~700MB download
- **No editing**: View and measure only (no modifying geometry)
- **No cloud sync**: Files must be on local or network storage

### Best For
- Construction site offices (offline access)
- Reviewing large drawings (no file size limit)
- Batch converting DWG versions
- Comparing drawing revisions
- Printing full-size plots

## Autodesk Online Viewer

### Pros
- **No installation**: Works in any browser
- **Cross-platform**: Windows, Mac, Linux, tablets
- **Excellent 3D**: Smooth 3D model viewing with sectioning and exploded views
- **Markup**: Cloud-based markups with comments
- **Sharing**: Share via link — no file transfer needed
- **Multiple formats**: DWG, RVT, IPT, STEP, IGES, and more

### Cons
- **File size limit**: 200MB per file
- **Internet required**: Can't work offline
- **No batch operations**: One file at a time
- **No DWG Convert**: Can't convert DWG versions
- **No DWG Compare**: Can't compare drawings
- **Slower for large 2D drawings**: Browser rendering is slower than desktop

### Best For
- Quick review on any device (including tablets)
- Sharing drawings with clients via link
- Viewing 3D models (Revit, Inventor, Fusion 360)
- Teams that need cloud-based markup and comments

## AutoCAD Web

### Pros
- **Limited editing**: Can add lines, text, and basic geometry
- **Cloud storage**: Auto-save to Autodesk Drive
- **Cross-platform**: Any browser
- **AutoCAD familiarity**: Interface similar to AutoCAD

### Cons
- **File size limit**: 50MB
- **Limited tools**: Very basic editing (no advanced AutoCAD commands)
- **Internet required**: No offline mode
- **Performance**: Slower than desktop for large drawings
- **Subscription for full features**: Free version is limited; full editing requires AutoCAD subscription

### Best For
- Quick edits on the go (add a note, mark a revision)
- Viewing and minor editing when away from the office
- Collaborative editing (multiple users can view simultaneously)

## Third-Party Viewers

### eDrawings (Dassault)

- **Best for**: SolidWorks files (SLDPRT, SLDASM) and DWG/DXF
- **Pros**: Excellent 3D viewing, cross-platform, free
- **Cons**: DWG support is limited (no AutoCAD engine — rendering may differ)

### Bentley View

- **Best for**: MicroStation files (DGN) and DWG
- **Pros**: Handles very large files, DGN support
- **Cons**: Interface is different from AutoCAD, large installation

### LibreCAD

- **Best for**: DXF files (not DWG)
- **Pros**: Open source, lightweight, cross-platform
- **Cons**: DXF only (can't open DWG directly), limited features

## Our Recommendations

### For a construction site office:
**DWG TrueView**. Offline access, full plotting, no file size limits, and batch operations make it ideal for site environments with unreliable internet.

### For a client reviewing drawings:
**Autodesk Online Viewer**. No installation needed — just send a link. The client can view, measure, and markup in their browser without any CAD software.

### For an engineer on the go:
**AutoCAD Web**. View drawings from any device and make minor edits (add a note, mark a revision) without returning to the office.

### For a Mac user:
**Autodesk Online Viewer** or **AutoCAD Web**. DWG TrueView is Windows-only, so Mac users need a browser-based solution.

### For batch conversion and comparison:
**DWG TrueView**. No other free tool offers batch DWG conversion and DWG compare.

### For viewing 3D models (Revit, Inventor):
**Autodesk Online Viewer**. The 3D viewing experience is superior to DWG TrueView, with smooth sectioning, exploded views, and measurement tools.

## Workflow Recommendation

For most engineering and construction firms, we recommend **both** DWG TrueView and the Autodesk Online Viewer:

1. **Install DWG TrueView** on office workstations for:
   - Daily drawing review
   - Batch plotting
   - DWG version conversion
   - Drawing comparison
   - Offline access

2. **Use the Autodesk Online Viewer** for:
   - Sharing drawings with external stakeholders
   - Reviewing on mobile devices
   - Viewing 3D models
   - Collaborative markup

This combination covers all use cases without any software cost.
