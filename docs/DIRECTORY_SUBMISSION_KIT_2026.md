* **Built With / Tags**: `Next.js`, `TypeScript`, `Tailwind CSS`, `HTML5 File API`, `WebAssembly`, `CAD`, `Engineering`
* **About the Project (Story & Pitch)**:
```text
### Inspiration
Engineering teams frequently suffer from multi-CAD data exchange friction: drawing version mismatch errors ("Drawing file is not valid") and unexpected press-brake flange cracking due to inaccurate K-factor calculations. Traditional solutions require bloated desktop CAD installations or uploading confidential blueprints to untrusted conversion clouds.

### What it does
CADGuide.tools provides zero-cloud, client-side engineering tools alongside an open CAD comparison matrix:
1. Client-Side DWG Inspector: Uses HTML5 Blob slicing to read the first 6 bytes of native AutoCAD DWG files, identifying versions (AC1015 to AC1032) in under 5ms without server uploads.
2. Sheet Metal K-Factor Calculator: Mathematical solver for neutral axis shifts, bend allowance (BA), and bend deduction (BD).
3. CAD Directory & Matchmaker: Side-by-side comparison of 50+ 2D/3D CAD platforms covering licensing models, geometric kernels (Parasolid, ACIS, Open Cascade), and API support.

### How we built it
Built with Next.js static site generation (SSG) deployed at the edge. The binary parser runs entirely inside browser memory via typed ArrayBuffers, ensuring 100% data privacy for defense and aerospace blueprints.
```
